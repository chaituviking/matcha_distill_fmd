HOW TO RUN — distill-fmd
========================

Consistency distillation of a flow-matching TTS decoder (Matcha-TTS).
Everything runs on CPU. No GPU needed. Tested on macOS (Apple Silicon),
Python 3.11.

Read README.md for what it does and the results. This file is just the
commands.


0. What you need first
----------------------
- Python 3.11
- espeak-ng installed on the system (the phonemizer needs it)

  macOS:          brew install espeak-ng
  Debian/Ubuntu:  sudo apt-get install espeak-ng

First run downloads ~400 MB of Matcha/HiFi-GAN checkpoints, and the eval
harness downloads whisper-small / ECAPA / SQUIM (a few hundred MB more).
After that everything is cached and offline.


1. Clone
--------
git clone https://github.com/chaituviking/matcha_distill_fmd.git
cd matcha_distill_fmd


2. Environment
--------------
python3.11 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt


3. Run the three steps
----------------------
# a) teacher sanity: text -> wav. Writes results/teacher_sample.wav (non-silent).
python teacher.py --text "The meeting is at 4:30 PM on March 3rd." --nfe 16

# b) one distillation step + 60-step smoke loop.
#    Prints "single step OK ..." and a loss trend that goes down.
#    Saves results/student_smoke.pt (the harness picks it up).
python train_step.py

# c) full eval harness: cost + quality, teacher@{32,16,8,4,2} vs student@{1,2,4}.
#    ~5-8 min on CPU. Writes results/table.md, results/rtf_vs_nfe.png,
#    sample wavs in results/audio/, transcripts in results/transcripts/.
python eval_harness.py


4. What you should see
----------------------
- teacher.py     -> "wrote results/teacher_sample.wav (non-silent, ~3.5s of audio)"
- train_step.py  -> "single step OK: loss=... max|grad|=... params updated"
                    then a smoke loop and "trend over 60 steps: ... (down, +~60%)"
- eval_harness.py-> prints the cost/quality/agreement/code-mixed tables and
                    writes results/table.md


5. Useful flags
---------------
# if a metric model fails to download, skip it instead of crashing the run:
python eval_harness.py --skip-asr --skip-speaker --skip-mos

# shorter/faster train_step (fewer prompts, fewer smoke steps):
python train_step.py --n-prompts 2 --steps 10

# change the NFE sweep:
python eval_harness.py --teacher-nfe 16,8,4 --student-nfe 1,2


6. Files
--------
teacher.py       - loads pretrained Matcha, exposes velocity_field /
                   trajectory_point / encode / synthesize
student.py       - the consistency student (one-step + multistep samplers)
losses.py        - consistency-distillation loss
train_step.py    - one optimizer step + smoke loop (full training is a stub)
eval_harness.py  - cost + quality measurement, writes results/
prompts.txt      - 12 test sentences (numbers, a Hinglish line, a long one, etc.)
writeup/serving_design.md - Part 2, the serving design
cosy_exp/        - the CosyVoice 2 comparison writeup + notes (see section 7)
results/         - generated by the harness


7. Optional: the CosyVoice 2 second-teacher experiment
------------------------------------------------------
The writeup and numbers for this are in cosy_exp/ (model_compare.md and
cosy_notes.txt) and are included in this repo. The runnable experiment code
itself is NOT in this repo -- it's a separate, heavier setup (CosyVoice isn't
pip-installable and needs a ~5 GB model), so it's kept out of the main
deliverable. For reference, the steps I used were:

  git clone https://github.com/FunAudioLLM/CosyVoice.git /tmp/CosyVoice
  export PYTHONPATH=/tmp/CosyVoice:/tmp/CosyVoice/third_party/Matcha-TTS
  export COSYVOICE_ROOT=/tmp/CosyVoice
  # download iic/CosyVoice2-0.5B via modelscope into models/CosyVoice2-0.5B
  # with teacher_cosyvoice.py present:
  python train_step.py --teacher cosyvoice          # shows the 320-vs-160 blocker
  python eval_harness.py --teacher cosyvoice --out-dir results_cosyvoice \
      --skip-asr --skip-speaker --skip-mos           # CosyVoice cost curve


Troubleshooting
---------------
- "espeak-ng not found" -> install it (step 0). On macOS the code auto-finds the
  Homebrew .dylib; if it's elsewhere, set PHONEMIZER_ESPEAK_LIBRARY to the path.
- A metric download hangs/fails -> re-run with the matching --skip-* flag.
- Cost numbers differ run to run -> expected; CPU wall-clock jitters ~10-15%.
  The RTF ratios (~30x decoder, ~0.11 total floor) are the stable part.
